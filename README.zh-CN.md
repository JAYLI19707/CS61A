# CS61A 学习笔记

[English](README.md)

本仓库记录了加州大学伯克利分校 CS61A（*Structure and Interpretation of Computer Programs*）课程的学习笔记和作业练习。

## 项目

| 项目 | 说明 |
|------|------|
| **Hog** | 骰子游戏，练习高阶函数与控制抽象 |

## 实验

- Lab 00 ~ Lab 05：基础实验，涵盖 Python 语法、控制流、高阶函数、递归和数据结构
- Lab 04.5：数据抽象的额外练习

## 作业

- **HW02** — 高阶函数
- **HW06** — SQL 查询
